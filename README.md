# Political Girl

A simple 2D Java game project with sprite-based movement and directional walking animation.

## Features
- Four-direction player movement
- Directional idle sprites
- Walking animation
- Custom sprite sheet integration

## Tech Used
- Java
- Swing / Graphics2D

## How to Run
Open the project in VS Code or another Java IDE and run `Main.java`.

## Project Structure
- `src/` - Java source code
- `sprites/` - player sprite sheet assets
